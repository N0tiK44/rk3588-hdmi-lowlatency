# V3.3 result — capture buffer sweep

V3.3 varied the V4L2 capture pool while keeping the direct NV24 DMA-BUF → KMS path unchanged.

## Result

- **3 buffers:** cadence starvation.
- **4 buffers:** stable ~59.94/60 Hz delivery on the development setup.
- Larger pools were investigative; the key engineering result is that **four buffers are the minimum stable pool**.

## Consequence

Four capture buffers are now the default for baseline and V3.5 runs. Three remains accepted by the binary only so starvation can be reproduced deliberately; it is not the recommended operating configuration.

This result shifted investigation away from the hypothesis that HDMI-RX itself was inherently delivering only ~30 Hz and toward buffer ownership / KMS completion timing.
