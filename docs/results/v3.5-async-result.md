# V3.5 atomic-async result

Test platform: Orange Pi 5 Plus, Rockchip vendor kernel `6.1.115-vendor-rk35xx`, four NV24 capture buffers.

The normal atomic run completed with stable ~16.67 ms cadence and retained the V3.4 timing signature. The DRM device did not advertise `DRM_CAP_ATOMIC_ASYNC_PAGE_FLIP`; the one diagnostic async atomic commit was rejected with `EINVAL` (`Invalid argument`).

This is the expected unsupported result for this driver and does not invalidate the baseline. V3.5 did not fall back to GStreamer, copying, conversion, legacy page flips or implicit buffer lifetime guesses.

Observed normal-path medians in the captured run included approximately:

- previous OUT → DQ: 0.041 ms
- previous OUT → commit: 0.045 ms
- atomic commit ioctl: 0.056 ms
- commit → OUT: 16.566 ms
- own OUT → QBUF: 16.695 ms

The next useful experiment is phase measurement on the working normal path, implemented as V3.6.
